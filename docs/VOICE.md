# Voice

How Welcome Wave writes. The founders' rule comes first: the app must not be filled with text. Give things room.

## Rules

- **One title, one line, then the work.** A page has a title, at most one helper line, and its content. A section has a
  short heading and, only if it is needed, one quiet line under it.
- **Short labels.** Headings and buttons are one to three words. Buttons start with a verb: *Ask*, *Save*, *Run review*,
  *Schedule session*.
- **Say what it does for the reader**, not how it works inside. "Answers cite the code, documents and KT sessions", not
  "retrieval over indexed chunks".
- **Numbers over adjectives.** "3 of 5 done", not "great progress". "Not enough data" rather than a misleading 0.
- **Empty, loading and error states are designed.** Empty: a title that states the fact, one line on what happens next, at
  most one action. Loading: skeletons in the page's own shape. Error: what went wrong, then what to do.
- **Sentence case.** No exclamation marks, no emojis, no "Oops". British spelling (organisation, colour).
- **Warmth is for people.** The pre-boarding page may say "Welcome, Arjun". Product pages stay quiet and factual.
- **Private means private.** When something is visible only to the reader, say so once, plainly: "Only you can see this."

## Vocabulary

| Say | Not |
|---|---|
| KT session | KT call, meeting, recording (when you mean the session) |
| explained (in a KT session) | covered, linked, matched |
| sources | chunks, context, retrieved documents |
| answer | response, completion, output |
| Ask a person | escalate (on a button) |
| sent to Ravi (mentor) | routed, assigned, ticketed |
| verified answer | expert-curated, golden answer |
| reading the repository | ingestion, indexing pipeline |
| assistant | supervisor, LLM, model, agent runtime |
| first task | starter ticket |
| private review | presubmit, pre-submit check |
| not enough evidence | low confidence, below threshold |

## Never in the interface

chunk, ingestion / ingest, supervisor, embedding, vector, egress, RAG, LLM, prompt, pipeline, tenant, payload, token (say
"link"), retrieval, similarity score, threshold. Admin-only settings may name a real product setting (Gemini API key,
webhook URL) when the reader has to type it somewhere.

## Colour is part of the voice

Black, white and greys. Teal means one thing only: **explained in a KT session**. Warnings use amber, failures red, and
both only when something needs the reader.
